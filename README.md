# koalaviewer
C64 KOALA Image viewer, written in C++ with QT6 libraries

# Description
This is a simple KOALA image viewer. The KOALA image was a common format of Hires-Multicolor Image (160x200), used in the Commodore64 era.

# Dependencies
QT6 libs

# Compilation
qmake6

make

# Usage
koalaviewer <.kla or .koa image file>
Or simply run it and use menu.
